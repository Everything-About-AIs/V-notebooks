## How to use

1. Click the "Open in Colab" or "Open in Kaggle" badge next to the notebook you want.
2. For Colab: connect to a GPU runtime (**Runtime -> Change runtime type -> T4 GPU**).
3. For Kaggle: set **Settings -> Accelerator** to a GPU and turn on **Internet**.
4. Run the cells in order.
